# 전체 지도 관수 구역 추가·편집

전체 지도에서 구역의 위치를 확인하고 편집한다. 저장한 경계는 위도·경도이며, 정원 상세에는 이름표와 선택 요약이 표시된다. 초기 A–X와 이전 픽셀 편집본은 예시 배치로 불러온다.

1. **전체 지도 → 정보 → 새 구역 추가**에서 이름을 입력하고 지도에 점을 3개 이상 놓는다. 첫 점을 누르거나 **경계 닫기**로 닫은 뒤 저장한다.
2. 기존 구역은 목록의 연필 버튼을 누른다. **점 선택(V)** 으로 위치를 조정하고, **점 추가(P)** 로 경계 위에 점을 놓는다. **곡선(C)** 에서 직선을 누르고 보라색 조절점을 끌면 굽기를 바꿀 수 있다.
3. Shift+드래그로 축을 제한하고 방향키로 미세 조정한다. ⌘/Ctrl+Z는 실행 취소, ⌘/Ctrl+Shift+Z 또는 Ctrl+Y는 다시 실행이다.
4. **변경사항 저장**은 현재 브라우저에 반영한다. **편집 취소**는 저장 상태로 돌아간다. 미저장 경계를 두고 정원 상세로 전환하면 확인창이 표시된다.
5. **GeoJSON 내보내기**는 저장된 구역을 FeatureCollection 파일로 내려받는다.

새 구역의 경로 미리보기에는 관수 접근 지점 연결이 필요하다. 경계를 수정해도 이미 연결된 접근 지점이 자동 이동하지 않는다.

저장한 값은 현재 사이트의 브라우저에 유지된다. 다른 탭의 오래된 수정은 저장 버전을 검사해 거부한다. 저장 실패 시 초안을 유지한다. [저장 구조](garden-zone-api.md) · [정원 상세의 표시 범위](garden-detail.md)
