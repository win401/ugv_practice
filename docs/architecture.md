# 대시보드 구조와 구현 상태

## 확인한 사실

- `FE`는 React · Vite · TypeScript로 동작한다. 시연 계정은 백엔드 없이도 동작한다.
- 화면은 `FE/src/api/client.ts`의 API 함수만 부른다. 구현은 브라우저 안의 가상 서버(`mock.ts`)와 실제 서버(`httpApi.ts`) 둘이고, 로그인한 계정에 따라 갈린다. 시연 계정은 가상 서버를, 그 외 계정은 백엔드(MySQL)를 쓴다.
- 장비 통신은 없다. 표시된 연결 상태·배터리는 가상 데이터이거나 관리자가 넣은 값이다. 전체 지도는 V-world 위성 타일을 불러온다.
- 정원은 장미·초화·잔디 3곳이고 각각 지도 구역과 예시 경로를 가진다. 정원을 전환하면 지도 구역과 정보·이력이 그 정원 기준으로 바뀐다.
- 시연 기준일은 `2026.11.04`다. 데이터는 `localStorage`에 저장되어 고객·관리자 화면(다른 탭 포함)이 함께 쓴다.
- 운영자 화면(`/`)·관리자 화면(`/admin`)·로그인(`/login`)으로 나뉜다. 가상 서버의 권한 검사는 흉내일 뿐 보안 장치가 아니다. 실제 서버는 경로별 접근 규칙과 로그인 쿠키로 검사한다([BE README](../BE/README.md#로그인)).

## 완료한 작업

| 파일·영역 | 책임 |
| --- | --- |
| `FE/src/App.tsx` | 앱 진입 화면 연결 |
| `FE/src/views/WorkspaceView.tsx` | 탭·정원 선택, 지도 도구, 패널·알림 조합 |
| `FE/src/views/WorkView.tsx` | 관수 진행·사용량·구역 목록 |
| `FE/src/views/EquipmentView.tsx` | 장비 일러스트와 가상 상태 |
| `FE/src/views/HistoryView.tsx` | 필터 결과·이력 상세 표시 |
| `FE/src/components/` | 헤더·항공사진 기반 지도(구역·경로 SVG)·UGV 그림·종료 확인 창 |
| `FE/src/hooks/useIrrigationSimulation.ts` | 타이머, 진행 상태 전이, 완료·종료 이력과 토스트 |
| `FE/src/api/` | API 함수·타입, 가상 서버(`mock.ts`)와 시연 데이터(`seed.ts`), 실제 서버 구현(`httpApi.ts`, `http.ts`), React Query 설정(`queryClient.ts`, `useApiData.ts`) |
| `FE/src/admin/` | `/admin` 관리자 화면. 실제 계정의 정원 등록(위성지도 경계 그리기) 포함 |
| `BE/` | 로그인, 계정·정원·장비 관리, 주소 검색 중계, 운영 화면 조회 API |
| `FE/src/views/LoginPage.tsx` | 로그인 화면 |
| `FE/src/lib/gardenRoute.ts` | 진행률에 따른 예시 좌표 계산 |
| `FE/src/types/dashboard.ts` | 탭·작업 상태·구역·이력 타입 |
| `FE/src/styles/` | 공통 토큰·헤더·지도·패널·장비·이력·오버레이·반응형 규칙 |

종료 확인 창은 키보드 포커스 순환과 Escape 닫기를 지원한다. 데스크톱에서는 오른쪽 패널, 768px 미만에서는 하단 패널로 바뀐다. 패널 본문만 스크롤하고 작업 버튼은 하단에 유지한다.

## 검증

구조 변경 후 포맷 검사·TypeScript 검사·Vite 빌드와 브라우저의 주요 동작을 확인한다. 수행 결과는 [업무일지](../work-log/2026-11-05.md)에 남긴다.

## 예정된 작업

- 미션, 회차·명령, 작업 기록(이력)의 서버 저장과 API. 지금은 브라우저에서만 동작한다.
- 관수 구역과 추가 정원 경계의 서버 저장. 지금 자료는 순천만국가정원 기준의 시연용이다.
- 등록한 정원의 경계 수정.
- 실제 장비 사양·메시지 규격에 따른 장비 통신과 표시 항목 조정.

구현된 것과 아닌 것은 [API 계약의 구현 상태](../FE/docs/api.md#구현-상태-2026-11-13)와 [BE README](../BE/README.md#아직-구현하지-않은-것)에 있다.

현재 목업을 운영 환경의 인증·보안·배포 구성으로 간주하지 않는다. 클라우드 계정 정보와 개인 인프라 기록은 이 저장소의 앱 소스와 분리해 관리한다.
