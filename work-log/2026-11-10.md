# FE
- 브라우저 탭 제목을 SAMGIL로 변경
- 장비 탭 UGV 일러스트를 실제 장비 이미지로 교체하고 GARDEN UNIT 01 라벨 삭제
- 장비 탭 제목을 ROVEN으로, 화면의 UGV-01 표기를 ROVEN-01로 변경
- 관리자 화면(/admin) 추가: 전체 현황, 고객·정원·장비 관리, 장비 상태 시뮬레이션
- 관리자 정원 관리: 전체 정원 검색·필터, 등록 승인·반려, 정보 수정, 장비 배정, 소유권 이전
- 관리자 장비 관리: ROVEN 등록(번호 자동 부여), 배터리·물 잔량·수신 상태 표시, 원격 명령(작업 중지·기지 복귀·회수)
- 화면이 API 함수만 부르도록 API 계층 분리 (지금은 브라우저 안의 가상 서버로 동작, 백엔드 연동 시 구현만 교체)
- 고객 화면과 관리자 화면이 같은 데이터를 쓰도록 통합 (관리자 쪽 변경이 고객 화면에 바로 반영)
- 고객 화면의 배터리·연결 상태·장비 번호를 고정값 대신 장비 데이터로 표시
- 새로 등록한 정원은 승인 대기로 시작하고, 관리자 승인·장비 배정 후 관수 가능하도록 변경
- 로그인 화면(/login) 추가: 관리자는 /admin, 운영자는 /만 접근하고 운영자는 자기 정원만 조회
- 고객 화면 헤더에 계정 메뉴(로그아웃) 추가, 정원이 없는 운영자는 첫 정원 등록 화면에서 시작
- 개발 서버 /api 프록시 설정 추가, API 계약 문서(FE/docs/api.md) 작성
